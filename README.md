# ortunate · Personal Space

英文深空个人站，基于 Astro、TypeScript、Three.js。包含 9 款游戏、12 个本地工具、12 种互动图样、3 个科学模拟 Lab，以及新闻、股市和在线工具跳板三个导航板块。本地工具和模拟在浏览器处理数据；外部来源在新标签页打开。

## 本地运行

使用 Node.js 24 LTS 或更新版本：

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

打开终端显示的本地地址。构建生成 51 个静态页面，输出到 `dist/`，不提交构建产物。限制文件系统环境可用 `ASTRO_TELEMETRY_DISABLED=1` 禁用 Astro 的遥测配置写入。

## 页面与内容

- `/`：首页星球，以及 Visuals、Tools、Play、News、Markets、Launchpad 入口。
- `/explore/`：汇总全部 73 个入口（包含 Lab 与创作工作台），支持全站搜索、跨板块收藏及按用途探索；首页搜索直达。顶部导航将外部导航板块集中到 Explore。
- Explore 个人工作台：最多置顶 6 个已收藏入口，显示最近打开的 8 个入口，可清空最近使用记录。站内详情页直达和目录外链点击均会记录；记录仅存于本地浏览器。
- 收藏管理支持 JSON 备份与合并导入（最大 64 KB）。保留原收藏和置顶顺序，过滤未知 ID，不加载备份提供的 URL；备份不包含最近使用记录。取消收藏会同时取消置顶。存储失败会提示导出备份。
- `/news/`：10 个科技、国际、中文与科学新闻来源；前往出版方阅读最新文章。
- News 内嵌 Hacker News 新闻流，提供 Top / Newest / Show HN 三栏、手动刷新、文章和讨论链接、来源及本地发布时间。通过官方公开 API 获取每栏最多 12 条，最多 4 个详情请求并发，12 秒超时；切换栏目取消旧请求，部分失败仍显示可用内容。缓存有效期 10 分钟，失败时最多保留 7 天内的旧快照并标明获取时间；不采集文章正文，不需要 API 密钥。
- News 支持稍后阅读（最多 50 条标题快照）、手动已读/未读标记（最近 200 条）、当前列表标题/来源搜索和仅看未读。Read later 不发起网络请求，刷新新闻不会删除收藏；只保存标题和链接等元数据，文章正文仍需联网访问。状态保存在 `ortunate:reading:v1` 并跨标签页同步；满额会提示移除旧条目，不自动挤掉收藏。
- `/markets/`：10 个全球、美股、港股、A 股及宏观研究入口；支持 Yahoo Finance 公司/代码查询和指数快捷链接。不内嵌实时价格。
- Markets 自选清单：最多 40 个美股/ETF、港股、沪市或深市代码，可设置名称、研究笔记、按市场筛选、编辑和删除后撤销。港股补齐四位数字、美股类别股点号转换为连字符；同市场同代码更新现有条目。仅检查格式，不验证上市状态。行情与新闻链接只携带代码，笔记保存在 `ortunate:watchlist:v1`，不随链接发送。
- `/launchpad/`：15 个设计、开发、日常、学习和趣味网站入口。
- 三个新板块支持搜索、分类、收藏筛选、随机探索及空结果重置。收藏保存在 `ortunate:bookmarks:v1`，跨板块共享、跨标签页同步；存储不可用时退化为本次页面访问内保存。无 JavaScript 时仍能打开全部链接。外部网站可能需要账号、订阅或上传数据。
- 全部目录复用 `src/scripts/discover.ts` 和 `src/lib/browse.ts` 的筛选逻辑。多关键词按 AND 匹配，忽略大小写并归一化全角字符；`q`、`category`、`saved=1` 保存在网址中，刷新和返回可恢复条件。比如 `/explore/?category=Tools&q=json`。探索页可收藏本地体验，旧外链收藏 ID 保持兼容。
- `/visuals/`：动态缩略展厅、分类和搜索；每种图样在 `/visuals/[slug]/` 有完整互动页。
- `/lab/`：独立实验目录，包含 `/lab/reaction/`、`/lab/sand/`、`/lab/lenia/`。
- `/play/`：9 款游戏的目录，每款独立页面，通过 `?mode=0`、`?mode=1` 等切换规则。
- `/tools/`：12 个工具的目录，每个工具独立页面；首页与工具目录的数量从数据自动生成。
- `/tools/diff/`：文本逐行比较、增删行高亮、原始/新版本行号、忽略首尾空白、仅显示变化、交换、复制。每侧最多 1,000 行与 100,000 字符，先检查大小再计算，避免无界计算；末尾换行作为空行比较。
- JSON 与编码工具可将输入/结果发送到比较页。只在点击按钮后写入当前标签页 `sessionStorage`，比较页读取即删除，超过 5 分钟拒绝使用；文本不写入网址。输入变化会禁用旧结果传递；存储不可用时提示手动复制。
- `/about/`：个人介绍。
- `/projects/`：兼容旧链接，跳转至 Visuals；旧工具锚点 `/tools/#timer`、`#json`、`#text` 跳转至对应工具。

### 游戏

| 游戏 | 规则变种 |
| --- | --- |
| Cosmic 2048 | 经典 4×4、宽松 5×5、同数连线、递增数字链 |
| Neon Snake | 经典、穿墙、固定障碍；三档速度 |
| Falling Blocks | 无尽计分、40 行竞速；预览、暂存、硬降 |
| Prism Break | 五关挑战、无尽波次；鼠标、触控、方向键 |
| Minefield | 9×9 / 10 雷、16×16 / 40 雷、30×16 / 99 雷；首击安全、标旗 |
| Echo Pairs | 4×4、6×4；自由练习与限时挑战 |
| Sliding Space | 3×3、4×4；数字和渐变皮肤；保证打乱可解 |
| Game of Life | 固定 / 环绕边界；绘制、单步、运行、滑翔机、脉冲星、随机预设 |

2048 连线允许横竖与斜向相邻格子，不重复经过格子，回退上一格撤销一步。拖动松手提交，也可以逐格点击后按 Connect。键盘方向键移动焦点，Space 选入，Enter 提交，Backspace 回退，Esc 取消。

- 同数连线：至少两个相同数字，总和向上取整至最近的 2 的幂，例如 2+2+2→8。
- 递增数字链：前两格相同，之后等于累计值，例如 2→2→4→8→16。
- 合并结果先落在路径终点，然后消除、重力下落并补入 2/4；合并值计分。无合法连接结束，达到 2048 可以继续。

快捷键只在游戏区域聚焦时生效。实时游戏切后台自动暂停，打砖块可按住方向键连续移动。成绩按游戏和模式隔离：扫雷和 40 行竞速记录最短完成时间，拼图记录最少步数，Life 不写最高分；旧计分记录保留在原存储键中。2048 与拼图自动保存棋盘，拼图恢复时验证可解性，经典 2048 兼容旧存档，经典贪吃蛇兼容旧最高分。其他游戏重进时开始新局。扫雷专家模式在窄屏内横向滚动，不挤小格子。

### 工具

番茄钟、JSON 格式化/压缩、字数统计、秒/毫秒时间戳转换、UTF-8 Base64 / URL 编解码、HEX/RGB/HSL 与 CSS 渐变、正则测试、密码生成、单位换算、随机抽签。

- 番茄钟默认 25/5 分钟，使用绝对时间处理后台停留；完成后手动开始下一阶段。
- JSON 和文本最多 200 万字符。文本不上传、不保存，输出以纯文本呈现。
- 正则在独立 Worker 中运行，1 秒超时终止，最多展示 2,000 个匹配；支持捕获组和 Unicode 零宽匹配。
- 密码使用浏览器安全随机数，每个选中的字符集至少出现一次，不保存结果。
- 随机抽签支持重复/不重复；不重复模式会先去重候选项。
- 单位包括长度、质量、温度、面积、体积；加仑与杯明确使用美制。
- 剪贴板权限不足时提示手动选择复制。
- 修改输入或规则会清除旧结果并禁用复制；文本、色彩和单位实时重算。正则的表达式、标志或文本任一变化都会取消旧任务，过期响应不能覆盖新结果。
- 色彩工具支持单独复制第一色的 HEX / RGB / HSL，以及完整渐变 CSS。

### 图样

Orbital Field、Ribbon Trails、Repulsion Grid、Gravity Wells、Flow Field、Ripple Surface、Aurora Curtains、Fractal Explorer、Kaleidoscope、Elastic Mesh、Flocking、Warp Tunnel。

每种两套预设，支持配色、速度、作用强度和专属参数。详情页支持全屏、PNG 导出、暂停、重置与随机预设。画布聚焦后：方向键控制作用点或相机，Enter 激发该图样的主要动作，Space 暂停，R 重置；星球与分形支持滚轮、捏合及 + / − 缩放。具体操作以侧栏为准。

- Orbital Field 与首页共用原版场景工厂：相同的暗色网格核心、9,000 点倾斜粒子环、极轨、几何参数和辉光。详情页增加拖动与缩放。
- Fractal Explorer 重做为 Mandelbulb / Mandelbox 三维分形雕塑，使用光线步进、表面法线、软阴影、环境遮蔽、金属材质与轮廓光。拖动绕行，Enter 切换慢速巡游；可调复杂度、材质与光照角度，预设切换淡出衔接。
- Warp Tunnel 重做为三层纵深的 GPU 实例化星尘，移除多边形环框。Deep Space 为疏朗深空，Dust Passage 为密集尘带。连续积分位移，按住鼠标或 Enter 平滑加速，松开缓慢减速；速度共同影响星轨长度、视野与转向。
- 缩略与详情共用场景实现；缩略目标 24fps，详情目标 60fps（实际速度取决于设备）。离屏和后台不绘制，较慢设备降低分辨率。
- GPU 图样在首次进入视口时初始化；总览共用一个 WebGL 渲染器，详情页直接渲染到主画布，其余效果用 Canvas 2D；不嵌入 iframe。单个 shader 失败不会禁用其他图样。
- 模拟推进与绘制分离，PNG 直接导出现有帧。暂停和减少动效不推进粒子状态；波纹有生命周期和数量上限；尺寸变化保留粒子位置，非结构参数不重置场景。
- Motion 设置遵循系统减少动效偏好，并可由页脚覆盖。WebGL 不可用时显示备用构图。

### Lab 实验工作台

- Growth textures：Gray–Scott 反应扩散，周期边界、零通量障碍，珊瑚/分裂/条纹预设；浓度与浮雕渲染。
- Sand ecology：沙、水、石、木、火、蒸汽、烟七种材料；密闭边界、确定性随机规则。非精密流体或热力学模拟。
- Lenia culture：单通道连续细胞自动机、径向多环核、Gaussian 生长函数、缓存核频谱的 FFT 卷积；Orbium/相遇/随机密度预设，密度/势场/生长率视图。Orbium 数据遵循 Bert Chan 的 MIT 许可，见 `public/licenses/lenia.txt`。
- Run/Pause、单步、重置、种子、128²/256² 网格、笔刷、笔画撤销、内存检查点。绘画自动暂停；改变网格需要明确重建，不静默重采样。
- A/B 从 A 的完整当前状态分支，保持相同 tick，同步推进；参数独立，笔刷可作用于 A/B/两者。复制 A→B 建立新分支点。
- 参数扫描使用当前 A 的同一状态和 RNG，1–2 个参数，每轴 2–5 个均匀采样，最多 25 格，每格 100–10,000 步。Worker 串行执行，可取消并保留完成格。结果载入 A 后，可将同一终止 tick 的另一格替换 B 进行同步比较。
- 指标每 10 步记录，最多保留最近 2,000 个样本；CSV 明确只导出保留区间。图表以模拟步数为横轴。
- IndexedDB 具名本地保存，支持完整 `.lab.json`、PNG、指标 CSV、扫描摘要 CSV。文件包含格式/模型版本、当前/初始/分支状态、参数、种子、RNG、tick、视图、指标及扫描结果；导入限制 64 MB，先校验后替换。
- 后台自动暂停，需要手动恢复。所有模拟计算在 Worker；渲染不推进状态。模型参数与网格不随性能变化，同环境同模型版本可重复，跨浏览器浮点误差可能累积。
- 不使用浏览器自动化做视觉验收。手动检查：运行/画笔/撤销 → A/B 参数分离 → 两格扫描后逐一加载 → 导出并重新导入续跑 → 手机参数抽屉 → 切后台暂停。

## 开发入口

### Living Canvas

`/studio/living-canvas/` 是独立的生成式材料创作页：一种 Gray–Scott 生长材料，矿物与釉面两种渲染风格，固定 256² 网格、密闭边界。首幅作品由种子生成并预演 700 步，完成后暂停；也可新建空白画布。

- Seed、Freeze、Thaw、Barrier、Erase 五种笔刷；冻结保留双浓度值并参与邻域扩散，屏障阻断扩散，擦除清空纹理和两种区域标记。
- 暂停编辑期间最多撤销 8 个笔画；开始生长或单步时清空笔画撤销。改变材质、灯光或浮雕强度不改变模拟状态。
- 模拟和材质绘制使用独立 Worker；较慢设备减少显示更新或降低实际步速，不跳步、不改变网格。切后台暂停，返回需手动继续。
- IndexedDB 独立作品库，保存始终创建新副本，带缩略图；导出 1024² PNG（无编辑覆盖层），或可续编辑的 `.living.json`（含浓度、冻结/屏障、种子、步数及材质）。导入最多 8 MB，先验证后替换；存储失败可继续使用并导出文件。
- 首页、Lab 目录、Explore 均有入口，支持收藏和最近访问。未加入多图层、选区变换、时间回溯、视频导出或账号同步。
- 手动验收：播种→生长→冻结局部→继续生长→解冻；切换两种材质；保存→重载→打开续编辑；导入导出；手机触控与键盘画笔。没有使用 Computer Use 验收视觉效果。

## Kinetic Workshop

`/play/kinetic/` 是 2D 物理、2.5D 材质渲染的机械解谜工作台；`?mode=1` 直达 Workshop。WebGL 不可用时自动切换可编辑的 Canvas 2D 视图，也可手动切换。

- Challenges：六个直接可选关卡，通关记录保存在本地。五种零件：直轨、圆形碰撞器、发射板、中央铰链跷跷板、旋转臂。六关均有独立、未打包进前端的测试解法。
- Workshop：空白画板与三个示例；移动发射源和接收杯，指定固定零件、玩家库存及 1–5 颗球。试玩采用玩家规则，通过后才可导出挑战；修改设计会使验证失效。挑战文件排除可移动解法，草稿保留全部布局。导入挑战不保证可解。
- 编辑：选取、拖动、复制、删除、数值属性、网格吸附、15° 旋转、最多 50 步撤销/重做。画板聚焦时方向键微调、R/Shift+R 旋转、Space 运行/暂停；触屏支持双指平移和缩放。
- Rapier 0.21.0 在独立 Worker 中以 120 Hz 固定步长运行，球启用 CCD。最多 80 个零件、5 颗球、30 秒模拟时间；球间隔 2 秒释放，杯中低速停留 0.5 秒才计数，任意球出界即失败。发射板是接触触发的冲量，不是弹簧模型。
- 运行时锁定布局，支持暂停、单步及 ¼ 速；回到编辑恢复初始布局。最近一次运行可回放、拖动时间轴、查看轨迹和跳转碰撞事件；回放不推进物理。后台自动暂停，手动恢复。
- IndexedDB 保存设计、320×200 缩略图与进度，始终保存新副本；可导入/导出版本化的 `.kinetic.json`，上限 256 KB。不保存引擎内部状态与回放，不上传数据。存储或物理加载失败会明确提示，草稿仍可导出。
- `src/lib/kinetic/`：模型、编辑历史、物理、Worker 协议、渲染、回放与存储；`tests/kinetic.test.ts` 覆盖关卡可解性、固定零件与预算、确定性、CCD、回放、导入边界和真实 Worker 运行。

## Create 与 Sound Loom

`/studio/` 是轻量创作总览，连接 Living Canvas、Kinetic Workshop（Workshop 模式）与 Sound Loom。卡片使用静音 SVG 预览，仅可见时播放；不会加载各工作台引擎。首页与导航提供 Create 入口，既有 URL、收藏 ID 和独立作品库保持兼容。

`/studio/sound-loom/` 是温暖电子风格的六轨音序工作台：

- 六种本地合成音色：底鼓、军鼓、踩镲、打击音、低音、拨弦；空白工程与六个完整预设，无采样下载、麦克风或上传。
- 每轨 8/12/16/24/32 步，统一十六分音符；完整周期为各轨长度的最小公倍数，最多 96 步。60–160 BPM、50%–65% Swing、根音、大小调五声音阶和 Dorian 音阶。
- 音符开关、力度、概率、旋律音阶级数、锁定；每轨音量、声像、暖回声、静音和独奏。欧几里得节奏与种子旋律生成只修改选中轨的未锁定音符；同一种子与周期位置的概率结果可复现。最多 50 步撤销／重做。
- Web Audio 时钟约每 25 ms 预排未来 100 ms 的音符，绘图不驱动音频。播放中乐谱修改在下一小节一起切换并从新版本第 0 步开始，混音即时响应；暂停保留下一步，Stop 回到开头。后台或音频中断后需要手动恢复。
- Canvas 织线根据实际触发事件显示光点、余辉，旋律音高影响线的位置；减少动效时关闭形变和长余辉。网格支持键盘方向键、Enter 与 Space，窄屏使用选轨编辑。
- IndexedDB 独立作品库，每次保存创建新副本及缩略图；版本化 `.loom.json` 工程上限 128 KB。存储或音频不可用时仍可编辑及导出工程。
- WAV 离线导出 1/2/4 个完整周期，44.1 kHz、双声道、16-bit PCM，附 2 秒尾音，最多 98 秒；含尾音，不是无缝循环。导出使用点击时的工程快照，不受后续编辑影响。不同浏览器不承诺逐字节相同。
- 不自动发声；首次明确点击 Play 才创建音频上下文。所有编辑、生成和导出在本地运行，不提供视频、MIDI、音频上传、云同步或跨模块统一作品库。
- `src/lib/loom/` 分离工程模型、确定性事件、音频时钟、合成、绘图、文件与存储。测试使用可控时钟、音频节点和 DOM 事件适配器，不启动浏览器；真实音色、同步和触控仍需手动验收。

## 验证与手动检查

`npm test` 覆盖棋盘与连线规则、方块消行、蛇碰撞、扫雷首击安全、拼图可解性、生命游戏演化、计时、工具转换、安全随机数、正则 Worker 和隧道连续加减速。运行时测试通过事件/画布适配器检查暂停、导出、尺寸变化、资源释放、错误隔离、游戏状态、按键释放和过期结果，不启动浏览器。

`npm run build` 执行 Astro/TypeScript 检查，生成静态页面并验证 51 个路由及站内资源链接。Three.js 按需加载，构建可能提示其共享依赖包超过 500kB。

按用户要求，最终动效与移动端手感由用户手动验收，不再使用 Computer Use。建议优先检查：

1. Warp Tunnel 快速点击、长按、松开时位置连续，方向切换平滑。
2. Orbital Field 的粒子、辉光、预设和全屏；与首页原版星球比较。
3. Fractal Explorer 两种三维形态、光照/复杂度变化、拖动/捏合/滚轮缩放、Enter 巡游和暂停。
4. 2048 两种连线的拖动、键盘、回退、重开和存档恢复。
5. 游戏模式切换、手机布局、触控、后台暂停，以及工具错误输入。
6. Kinetic Workshop 六关与自由搭建、3D/2D 切换、触控编辑、运行回放、保存和挑战导入导出。
7. Sound Loom 首次播放授权、六个预设、混音、暂停/后台恢复、下小节切换、长轨滚动、工程及 WAV 导出；Create 三个入口和减少动效。
8. 减少动效、存储禁用、WebGL 不可用、剪贴板拒绝的提示与降级。

## Image Bench 与 Color Workshop

- `/tools/image/`：本地静态 PNG/JPEG/WebP 裁剪、旋转、翻转、缩放和真实编码对比；50 步撤销，质量或目标体积模式，最多 8 次编码，不暗中降低尺寸。最多 10 张图片串行批处理、取消后保留已完成结果、单张重试和 ZIP 下载。
- 每张输入最多 20 MiB / 2400 万像素，批量输入及结果分别最多 100 MiB；输出最长边 8192、最多 1600 万像素。拒绝动画和 HEIC/SVG。重新绘制后编码不复制原文件 EXIF/GPS，色彩遵循浏览器解码行为。
- 从实际编码结果提取 3–8 色（透明度加权），导出版本化 JSON，或发送到 `/tools/color/`。Color Workshop 支持 1–8 色编辑排序、CSS 变量导出、渐变、HEX/RGB/HSL 和不取整的 WCAG 文本对比度判定；色板导入不会自动替换渐变或对比色。
- Living Canvas 可准备不含编辑覆盖层的 1024px PNG 快照，另开 Image Bench。跨工具内容仅在主动操作时进入临时 IndexedDB，随机令牌链接有效 5 分钟，读取后删除，下次访问清理过期数据。存储不可用时下载并手动导入。原图和编辑状态不自动持久化。
- 检查采用命令行单测、类型检查、构建、链接及体积预算；真实浏览器编码、触屏裁剪和视觉效果仍需手动验收。

## GitHub Pages 发布

沿用 `.github/workflows/deploy.yml`。需要发布时，将源码推送到 `main`，仓库 Pages 的来源选择 GitHub Actions。当前配置对应 `https://ortunate.github.io/`，采用静态目录 HTML，详情页支持直接访问和刷新。

本地开发不会自动发布；推送到 `main` 后，由上述 GitHub Actions 工作流构建并部署。

## 后续深化方向

### 性能与代码维护

- Explore 工作台直接从页面已渲染的卡片提取标题、链接和分类，避免在客户端再次打包完整目录。本轮构建的入口及静态依赖从 22.6 KiB 降至 11.3 KiB（未压缩 JS）。
- 首页星球仅在进入视野、页面可见且启用完整动态效果时加载 Three.js；减少动态效果时保留 CSS 星球。已加载后仍保留原有暂停与恢复行为。
- `npm run build` 会自动运行 `scripts/check-performance.mjs`，递归计算代表页面入口的静态 JS 依赖并检查体积预算；不包含动态导入、CSS、字体或网络运行时数据。gzip 数值仅为估算，不代表完整页面加载量或测速结果。
- 3D 引擎仍是大型动态资源，构建器的大文件提示保留；本轮优化延后其加载，没有通过调整警告阈值隐藏问题。

### 下一步

按使用价值逐步增加功能，每轮优先打通一条完整使用路径：

1. **个人工作台（已实现基础版）**：置顶、最近使用和 JSON 导入导出已接入。后续可增加手动排序和用户自定义分组，继续复用同一目录 ID。
2. **新闻阅读（已接入首个来源）**：Hacker News 新闻流、缓存、错误回退、稍后阅读与已读标记已完成。后续再增加更多允许聚合的来源；数据获取独立于展示，保留直接访问来源的入口。
3. **股市观察（已实现本地清单）**：自选代码、研究笔记、多市场筛选和查询链接已接入。后续接入行情前明确数据授权、延迟和交易日历，API 密钥保留在服务端。避免把浏览器时钟当成真实开市状态。
4. **工具协作（已打通首条路径）**：JSON / 编码输入与结果 → 文本比较已实现。后续可增加格式转换与文件导出，继续只在用户主动操作时传递内容，大段文本不写入网址或长期存储。

设计沿用全局颜色变量、字体、按钮、间距和卡片层级；优先复用组件并保留键盘焦点、减少动态效果和窄屏布局。目录数据只维护一处，聚合页面自动派生；行为抽取到小型模块，不引入客户端框架或全局状态库。
